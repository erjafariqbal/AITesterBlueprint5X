# Playwright Framework using AI

Playwright + TypeScript automation framework for the Wingify (VWO) login page, generated from the RICE-POT prompt in `PROMPT-RICE_POT.md`.

## Tech stack
- Playwright Test with TypeScript
- Page Object Model
- Allure reporting (`allure-playwright`)
- dotenv for environment configuration
- GitHub Actions CI

## Project structure
```
PlaywrightFramework/
├── allure-results/      generated by test runs
├── pages/               Page Objects (LoginPage)
├── testdata/            qa.env
├── tests/               validLogin.spec.ts, invalidLogin.spec.ts
├── utils/               Env helper, globalSetup (logs in once, saves auth.json)
├── playwright.config.ts
└── package.json
```

## Setup
```
npm install
npx playwright install chromium
```

Create `testdata/qa.env` (git-ignored, never commit credentials):
```
BASE_URL=https://app.vwo.com/#/login
USER_USERNAME=<valid email>
USER_PASSWORD=<valid password>
INCORRECT_USERNAME=unregistered.user@example.com
INCORRECT_PASSWORD=WrongPass@123
```

## Run
```
npm test
npm run test:headed
```

## Allure report
```
npx allure generate allure-results -o allure-report --clean
npx allure open allure-report
```

## Test cases
- Valid: login with valid credentials, login with Remember me selected
- Invalid: incorrect username, incorrect password

## Known limitations
- `dashboardIdentifier` in `LoginPage` is an unverified locator (`getByRole('navigation')`); confirm it with a real account.
- Valid-login tests fail until real credentials are set in `qa.env`.

## CI
The root workflow `.github/workflows/playwright.yml` runs this framework and `PlaywrightFramework2` as two jobs. This one uses the repository secrets `VWO_USER_USERNAME` and `VWO_USER_PASSWORD` (and optionally `VWO_BASE_URL`) and uploads `allure-results`.
